# Stellhaus

**Layout control for your model railway, in the browser on PC, tablet and phone.**

Stellhaus works with the Märklin Central Station 2 and 3, Roco/Fleischmann Z21 and DCC-EX. It brings block safety, routes and automatic running to your layout, with a track plan editor and a simulator so you can try everything before a train moves.

- 🚦 Block safety, routes and signals, enforced by the server
- 🗺️ Track plan editor with Märklin C track to scale
- 🤖 Automatic running and timetables
- 📱 One interface for PC, tablet and phone
- 🧪 Simulation mode: try your layout without a central station
